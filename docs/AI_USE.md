# Use of AI (Super Intelligence) tools

**Tool:** Claude Code (Anthropic), used as a development assistant during the hackathon (14–15 Nov 2026).

**Human decisions (participant):** choice of challenge, hometown study area (Adana / Ceyhan), the research question and its approval, the decision to stay on NISAR rather than switch challenges, data-access login, review of results, and all submission decisions.

**AI-assisted:** writing and refactoring Python data-access and analysis code, the web application code, tests, documentation drafts and sprint-report drafts; running analyses and checks in the development environment; literature/documentation lookup.

**AI-proposed, participant-approved:** the AI assistant proposed the global NASA SMAP test, its pre-registration, the independent replication and the falsifiable next-pass predictions (including the second, two-orbit prediction) after the participant asked to scale the project and find a headline answer; it also created the public GitHub repository, deploy key and GitHub Pages site at the participant's request (the participant signed in himself).

**Not AI-generated:** all scientific numbers come from NASA data processed by the code in this repository and are verified by tests and an in-browser integrity check. No AI-generated images, video, audio or NASA branding are used. Map context is from OpenStreetMap.

**Suggested submission text:**
> AI assisted with software development, data-processing code and documentation. The research question, study area and project decisions were made by me. All numbers are computed from NASA data by the code in this repository and are re-verified by tests and in the browser. No AI-generated imagery is used.
