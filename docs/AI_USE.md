# Use of AI

**Tool:** Claude Code (Anthropic), used as a development assistant during the hackathon (14–15 Nov 2026).

**Deniz Efe Bulut (participant):** conceived the core project idea, the research question, the choice of location (Ceyhan, Adana) and the overall project direction. Every key decision is mine, including reviewing, approving and formally adopting the methodology, the locked predictions and the product framing ("Rain fools radar. Between Passes shows what really changed.") as part of the project.

**AI (Claude Code):** handled the coding, data analysis and document drafting, and proposed the statistical tests (the worldwide test, its pre-registration and replication), the prediction framework, and the weather-filter framing, which I evaluated and approved. It also set up the public GitHub repository, its deploy key and the GitHub Pages site at my request (I signed in myself).

**Not AI-generated:** every scientific number comes from NASA data processed by the code in this repository and is checked by automated tests and an in-browser integrity check. No AI-generated images, video, audio or NASA branding are used. Map context is from OpenStreetMap and Natural Earth.
